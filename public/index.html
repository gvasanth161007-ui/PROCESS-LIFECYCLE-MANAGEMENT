Key ideas

Process

A program in execution. The operating system tracks it from creation to termination.

Process Control Block (PCB)

The record the OS keeps for each process: PID, state, priority, program counter, burst and remaining time, memory, and timestamps. Open the PCB page to inspect one.

Scheduling

The scheduler picks which READY process gets the CPU. This simulator uses priority scheduling with one CPU.

Context switching

When the CPU moves from one process to another, the OS saves the old process's PCB state and loads the next one's.

Lifecycle

NEW → READY → RUNNING → (WAITING → READY, or SUSPENDED → READY) → RUNNING → TERMINATED.

Metrics

Waiting time is time spent in the Ready Queue. Turnaround time is termination minus arrival. Response time is first run minus arrival. CPU utilization is the share of clock ticks the CPU was busy.
